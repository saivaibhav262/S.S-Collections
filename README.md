# S.S Collections — Premium Fashion Showroom Website

The official landing page and digital lookbook for **S.S Collections**, an exclusive fashion showroom located at Gandhi Chowk, Tandur, Telangana.

This website is designed with a **visit-first architecture** to showcase the latest collections in Men's, Women's, and Kids' wear, while driving in-person customer visits through embedded Google Maps navigation and direct WhatsApp inquiries.

### Key Features
* **Showroom Showcase:** Clean, elegant lookbook displaying curated in-store categories.
* **Direct Foot-Traffic Drivers:** Integrated Google Maps location embed and instant directions.
* **Instant WhatsApp Inquiries:** One-click customer inquiry setup with pre-filled messaging.
* **Mobile-First Experience:** Sticky bottom action bar for fast navigation on mobile devices.
* **Pure Tech Stack:** Built with lightweight HTML5, CSS3, and modern JavaScript (no heavy frameworks required).

# S.S Collections

A modern, responsive business website for **S.S Collections**, a ready-made clothing showroom located in Tandur, Telangana.

The website is designed to showcase the store, clothing collections, product models, store information, and contact details in a premium and user-friendly layout.

## 🌐 Live Website

**Website:**  
https://saivaibhav262.github.io/S.S-Collections/

## 📍 About S.S Collections

S.S Collections is a ready-made clothing showroom located at:

**Gandhi Chowk, Tandur, Vikarabad District, Telangana – 501141**

The store offers clothing collections for:

- 👦 Boys
- 👧 Girls
- 👨 Men
- 👩 Women

The website provides customers with an easy way to explore the available collections and find store information before visiting.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Premium and modern clothing-store design
- Separate product models page
- Clothing collections organized by category
- Store location and contact information
- WhatsApp contact option
- Google Maps location integration
- Instagram link
- Mobile-friendly navigation
- Smooth scrolling and animations
- Optimized image-based product presentation
